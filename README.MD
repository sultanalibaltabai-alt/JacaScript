# Assignment 4: Forms and Validation

Student: Sultanali
Group: SE-2529

## Description
The goal of this project is to create user-friendly forms using basic HTML and Bootstrap 5 form components. It demonstrates both native HTML5 validation and custom Bootstrap validation with visual feedback.

## Project Structure
* `index.html` - Part 1: Basic HTML contact form with HTML5 validation.
* `part2.html` - Part 2: Bootstrap contact form with grid layout and validation styles.
* `part3.html` - Part 3: Advanced responsive registration form using Bootstrap.
* `style.css` - Basic styling for layout and basic form alignment.

## Instructions
1. Open the project via the published GitHub Pages or Netlify link.
2. Use the navigation bar at the top to switch between Part 1, Part 2, and Part 3.
3. Test HTML5 validation on the first page by leaving fields empty or entering an invalid email.
4. Test Bootstrap validation on the second and third pages by clicking "Submit" to see the success and error feedback messages.
5. Use the "Reset" button on the registration page to clear all form data.
